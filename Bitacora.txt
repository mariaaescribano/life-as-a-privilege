CONECTANDO CON SUPABASE

NUNCA escribas aquí la contraseña real: este fichero está en el repositorio y
cualquiera con acceso al código (o al historial de git) la vería. Las cadenas de
conexión van SIEMPRE en el .env local y en las variables de entorno de Render.

Formato (coge la cadena real del panel de Supabase → Settings → Database):

postgresql://postgres:[TU-PASSWORD]@db.[TU-PROYECTO].supabase.co:5432/postgres

Poner en env: DATABASE_URL="postgresql://postgres:TU_PASSWORD@db.TU_PROYECTO.supabase.co:5432/postgres"

Para migraciones usa el POOLER (IPv4); la conexión directa es solo IPv6.


Si usas TypeORM

En app.module.ts:

TypeOrmModule.forRoot({
  type: 'postgres',
  url: process.env.DATABASE_URL,
  autoLoadEntities: true,
  synchronize: true, // SOLO en local
})


Y asegúrate de tener:

npm install @nestjs/typeorm typeorm pg
